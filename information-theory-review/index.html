6.1.1–6.1.2 · Read the formulas

Surprise(x) = −log₂ p(x)
H(p) = −Σₓ p(x) log₂ p(x)
Hce(p,q) = −Σₓ p(x) log₂ q(x)

Σ means add across outcomes. Weight each surprise by how often that outcome really occurs. Entropy uses the true probabilities; cross entropy uses the model's probabilities inside the log.

A rare event is more surprising. An event with p = ¼ gives 2 bits of surprise.

  • 0 ≤ H(p) ≤ log₂ K for K possible states.
  • Deterministic outcome: H = 0. Uniform distribution: H = log₂ K.
  • A fair coin has 1 bit; a certain coin has 0.
  • Use 0 log 0 = 0 by continuity. Log base 2 gives bits; natural log gives nats.

Coding intuition: H(p) is the ideal average coding cost; using q instead costs Hce(p,q), with ideal/block coding qualifications.

02 / Complete the entropy picture

Combine, condition, and predict

6.1.3 · Joint entropy

How uncertain are we about the pair (X,Y)?

H(X,Y) = −Σₓ,ᵧ p(x,y) log₂ p(x,y)
max{H(X),H(Y)} ≤ H(X,Y) ≤ H(X)+H(Y)

Independent variables achieve the upper bound. If Y is determined by X, then H(X,Y) = H(X): Y adds no extra unknown information.

6.1.4 · Conditional entropy

How much uncertainty about Y remains after observing X, averaged over X?

H(Y|X) = Σₓ p(x) H(Y|X=x)
= −Σₓ,ᵧ p(x,y) log₂ p(y|x)
= H(X,Y) − H(X)

0 ≤ H(Y|X) ≤ H(Y). Independent: H(Y|X)=H(Y). Deterministic Y=f(X): H(Y|X)=0.

“On average” matters: one particular observation can increase uncertainty, even though the average cannot.

Chain rule: H(X₁,…,Xₙ) = Σᵢ H(Xᵢ | X₁,…,Xᵢ₋₁)

6.1.5 · Perplexity

The effective number of equally likely choices.

PPL(p) = 2ᴴ⁽ᵖ⁾
PPL(data,q) = 2ᴴᶜᵉ⁽ᵖᴰ,ᑫ⁾
= exp[−(1/N) Σᵢ ln q(xᵢ | contextᵢ)]

Uniform over K outcomes → PPL = K. Certainty → PPL = 1. Data perplexity is the geometric mean of inverse predicted probabilities.

For the same evaluation data and tokenization, lower is better. A mismatched model can have data perplexity above the vocabulary size. The population floor is 2ᴴ⁽ᵖ⁎⁾, not H(p*).

6.1.1 · Two supporting details

DNA sequence logos: estimate A/C/G/T frequencies at each position. Total column height is 2 − H(position), since log₂ 4 = 2. Conserved positions have taller columns; each letter's height is its frequency times the total.

Estimating entropy: plug-in estimates need a reliable distribution estimate. Many rare states (such as rare words) make this difficult with limited data.

Example: if Y copies a fair coin X, H(X)=H(Y)=1, H(X,Y)=1, and H(Y|X)=0.

Remember the assumption: mode covering/seeking describes common behavior with a restricted model family. If q can equal p, both objectives have the same optimum q=p. Gaussian densities are positive everywhere; this example demonstrates penalties for very small density, not literal zeros.

04 / 6.2.1–6.2.5

Why this becomes a learning objective

KL is the avoidable prediction cost

KL(p ∥ q) = Σₓ p(x) log[p(x)/q(x)]
= Hce(p,q) − H(p) ≥ 0

For continuous distributions, replace the sum by ∫p(x)log[p(x)/q(x)]dx. KL is zero exactly when the distributions agree (almost everywhere for densities).

KL is generally asymmetric and does not obey the triangle inequality, so it is a divergence, not a distance metric. Individual terms can be negative; the total cannot.

If p(x)=0 its term contributes zero. If p(x)>0 and q(x)=0, KL is infinite.

6.2.4 · Why is KL nonnegative?

Jensen's inequality: for convex f, f(E[Z]) ≤ E[f(Z)]. Since log is concave, the inequality reverses.

−KL(p∥q) = Eₚ log(q/p)
≤ log Eₚ(q/p)
= log Σₓ:ₚ₍ₓ₎>₀ q(x) ≤ 0

Equality throughout requires p=q. Applying this to uniform u gives KL(p∥u)=log K−H(p)≥0, proving the entropy upper bound.

6.2.5 · Maximum likelihood = minimum cross entropy

For data x₁,…,xₙ, pᴰ is its empirical distribution: each observation contributes mass 1/N (repeats accumulate).

Hce(pᴰ,qθ) = −(1/N)Σᵢ log qθ(xᵢ)
θ̂ = argminθ Hce(pᴰ,qθ)
= argmaxθ Σᵢ log qθ(xᵢ)

argmax means “the parameter value that makes this largest.” In the discrete setting, H(pᴰ) is constant with respect to θ, so minimizing KL(pᴰ∥qθ) is the same optimization.

For continuous models, the rigorous link uses the sample estimate of Eₚ[−log qθ(X)]; literal KL from point masses to a continuous density is infinite.

Training caveat: fitting the finite training sample can overfit. Data augmentation expands it with plausible variations; kernel density estimation is another way to smooth an empirical distribution.

6.2.3 · Gaussian KL formulas (natural logs → nats)

Let p=N(μ₁,σ₁²), q=N(μ₂,σ₂²).

KL(p∥q) = ln(σ₂/σ₁) + [σ₁²+(μ₁−μ₂)²]/(2σ₂²) − ½

For D-dimensional Gaussians with positive-definite covariance matrices:

KL(p∥q) = ½[tr(Σ₂⁻¹Σ₁) + (μ₂−μ₁)ᵀΣ₂⁻¹(μ₂−μ₁) − D + ln(det Σ₂ / det Σ₁)]

tr sums the diagonal entries; det is the determinant. The formula accounts for both mean and covariance mismatch. Same variance σ² gives KL=(μ₁−μ₂)²/(2σ²). Swapping different variances usually changes the answer.

05 / Active recall

Explain these before revealing

Why does q=p minimize cross entropy?

Hce(p,q)=H(p)+KL(p∥q). The first term is fixed, and the second reaches its minimum of zero at q=p. The minimum need not be zero: reality may still be uncertain.

Can observing X make Y more uncertain?

A particular observation can. But averaging over observations, H(Y|X)≤H(Y).

Why can reverse KL ignore an entire peak?

It averages over q. When q assigns almost no mass near a peak, that peak contributes almost nothing to the objective. A narrow fit avoids paying for the low-p gap between peaks.

Does a confident model necessarily have low data perplexity?

No. Confidence in the wrong outcome makes the observed outcome's probability tiny, giving large negative log likelihood and high data perplexity.

What connects all three main quantities?
Cross entropy = inherent uncertainty + model mismatch
Hce(p,q) = H(p) + KL(p∥q)
