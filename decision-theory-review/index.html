5 · Decision Theory / 5.1 · Bayesian decision theory

The chapter’s question: “What should I do?”

Inference gives a posterior belief. Decision theory turns that belief into an action.

observe x→ posterior p(h | x)→ loss for each action→ choose action
The conceptual jump“Most probable” and “best action” are not automatically the same thing. The best action depends on both probability and consequences.
5.1.1 · Basics

Expected loss is the engine.

There is an unknown state of nature h, a set of actions a, and a loss ℓ(h,a) for what happens if you take action a when h is the truth.

ρ(a | x) = E[ℓ(h,a) | x] = Σh ℓ(h,a) p(h | x)
π*(x) = argmina ρ(a | x)

So for every candidate action, multiply each possible loss by the posterior probability of the corresponding state, add them up, and pick the action with the smaller expected loss.

Equivalent utility viewIf U(h,a) = −ℓ(h,a), minimizing expected loss is the same as maximizing expected utility.

5.1.2 · Classification problems

A class prediction is just an action.

For classification, the hidden state is the true class and the action is the class label you choose to output.

state = true label y*→action = predicted label ŷ→loss depends on mistake type
5.1.2.1 · Zero-one loss

All mistakes cost the same.

Correct prediction → loss 0. Any incorrect prediction → loss 1.

ℓ₀₁(y*, ŷ) = I(y* ≠ ŷ)
ρ(ŷ | x) = 1 − p(y* = ŷ | x)

Minimizing that risk means choosing the class with the largest posterior probability.

Result: MAPŷ = argmaxy p(y | x). Under zero-one loss, “most probable class” really is the optimal action.
5.1.2.2 · Cost-sensitive classification

When mistakes are not equally bad, 0.5 is not sacred.

Let correct decisions have zero loss. Let ℓ₀₁ be the false-positive cost and ℓ₁₀ the false-negative cost.

predict 1 if p(y=1 | x) ≥ ℓ₀₁ / (ℓ₀₁ + ℓ₁₀)

If a false negative costs c times as much as a false positive, then the positive threshold becomes:

threshold = 1 / (1 + c)
Optimal probability threshold0.333

A false negative costs 2× as much, so you declare positive earlier.

5.1.2.3 · Classification with the “reject” option

Sometimes “I don’t know” is an action.

Add a reject action. Let λr be the reject cost and λe the classification-error cost.

λ* = 1 − λr/λe    and    p* = maxy p(y | x)
if p* > λ*: choose the most probable class; otherwise: reject

5.1.3 · ROC curves

One classifier, many thresholds.

Instead of treating a probability model as having one fixed cutoff, sweep the cutoff and observe the tradeoff between detecting positives and triggering false alarms.

Why a curve?Changing the threshold changes TP, FP, TN, and FN. Each threshold gives one point (FPR, TPR). Connecting those points gives the ROC curve.

AUC: area under the ROC curve.

AUC compresses the whole ROC curve into one number. In the textbook, larger AUC indicates a better ROC summary, with 1 as the maximum.

5.1.3.2 · Equal error rate

EER: where the two error rates meet.

EER is the point where FPR = FNR. Since FNR = 1 − TPR, the textbook finds it where the ROC curve crosses the line from top-left to bottom-right.
